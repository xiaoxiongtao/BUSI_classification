# DESIGN.md · 《乳腺癌智能诊断》教学课件

命中预设风格：**学术风**（教学课件 · 理工医）。以下为结合本项目锁定的参数，全篇硬约束。

## 1. 画布与母版

- 画布 1280×720，安全边距左右 40。
- 页眉模式全篇锁定 **A3**：深蓝顶条 `#0E3F8C`，高 72–88px，含中文主标（32–40px Bold 白色）+ 右侧章节标签。
- 内容区 y 80–660，宽 1200px，累计高 ≥476px。
- 页脚 y 660–700：左「BUSI 乳腺超声图像分类 · 乳腺癌智能诊断」14px `#8B97A8`；右页码 14px `#1E4FA8`，格式 `NN / 38`。
- 封面 / 目录 / 章节扉页 / 结束页省略页眉页脚，其余页必须遵守。

## 2. 色板（≤4 种主色 + 中性）

| 角色 | hex | 用途 |
| :-- | :-- | :-- |
| 主蓝 | `#1E4FA8` | 强调、编号、图表主序列 |
| 藏蓝 | `#0E3F8C` | 页眉顶条、章节扉页底、深蓝卡 |
| 浅蓝 | `#E8EFF8` / `#F0F5FC` | 卡片底、表格表头、斑马纹 |
| 中蓝 | `#3D7BD9` | 描边、图表第二序列、箭头 |
| 警示红 | `#D9534F` | 恶性类、漏诊警示，单页 ≤3% |
| 数据黄 | `#FFC107` | 关键数字高亮，单页 ≤3% |
| 文本 | `#1A2230` / `#4A5568` / `#8B97A8` | 主 / 副 / 辅助 |
| 线框 | `#D6DCE5` / `#E5E7EB` | 描边、表格线 |
| 背景 | `#FFFFFF` / `#F7F9FC` | 页面底 |

配色比：蓝族 35–55%、白底 30–55%、浅蓝 0–35%、红+黄 ≤5%。禁紫粉玫红 / 橙绿大色块 / 彩虹渐变 / 纯黑大底 / 金色。

## 3. 字体（≤2 套）

- 主字体：思源黑体（Source Han Sans / Noto Sans SC）——全篇中文、正文、标题。
- 辅字体：Times New Roman——仅用于封面英文长标题与引文。
- 字号：页眉主标 34 Bold；卡内标题 24–30 Bold/600；正文 22–28 Regular；表格 18–22；KPI 巨数字 72–110 Bold；注解页脚 14–16。正文不得低于 22px。
- 禁楷体 / 行书 / 艺术字 / 空心字 / 3D 字。

## 4. 版式与密度

- 内容页禁用大留白；卡片填充率 ≥80%；卡片填充仅白 / `#F7F9FC` / `#F0F5FC` / `#E8EFF8`。
- 深蓝实色卡单页 ≤1、全篇 ≤3；多卡页禁用深蓝实色卡。
- 多卡页必须有双重锚定：物理连接（箭头 / 节点串 / 共享外框）+ 共享锚点（底部强调条）。
- 每页 ≥1 个视觉锚点（≥44px 元素 或 ≥40% 内容区面积的图）。
- 相邻页版式不得重复；`左大图+右侧文字` 与 `非对称双栏` 合计 ≤40%。

## 6. 组件约定

- 表格：深蓝表头 `#0E3F8C` 白字；数据行浅蓝斑马 `#F0F5FC`；关键格浅黄 `#FFF8E1` 或浅红 `#FDECEC`。
- 公式：`<Math>` 组件，深蓝 `#0E3F8C`，宽度按内容 200–420。
- 代码：`<CodeBlock>`，`theme='github-light'`，`fontSize` 13–14，宽度 ≤640。
- 标签：浅蓝药丸 `#E8EFF8` + 深蓝字；深蓝编号方块 44×44；警示红药丸仅用于恶性/漏诊。
- 核心金句条单页 ≤1、全篇 ≤4。
- 所有公式与数据须真实可追溯：ResNet 引 He et al. 2015；ViT 引 Dosovitskiy et al. 2020；实验数字来自 `outputs/logs/ppt_model_summary.json`。
